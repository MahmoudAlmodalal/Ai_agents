# Ai_agents: الدليل الهندسي الشامل لبناء المشاريع ونمذجة الأنظمة بالذكاء الاصطناعي
### Comprehensive Engineering Guide: Building Software Projects & System Modeling with AI Agents

مرجع هندسي تفاعلي شامل ومفصل مقسم موضوعياً إلى **12 موضوعاً تخصصياً**: يغطي دورة حياة هندسة وتطوير الأنظمة البرمجية كاملة — من استنطاق الفكرة ووثيقة متطلبات المنتج (PRD) والمخططات الهندسية الثمانية (UML & ERD)، إلى المعمارية السحابية، وهندسة قواعد البيانات، وتصميم النظم البصرية، وتطوير الواجهات الأمامية بالذكاء الاصطناعي.

---

## 🌟 المحاور والمواضيع الهندسية الـ 12 (Core Topics)

1. **الموضوع 01: الأساسيات والمدخل الهندسي — بناء المشاريع البرمجية دون تخمين**
   - معضلة البرمجة التخمينية (Vibe Coding) وأهمية إغلاق باب التخمين.
   - قواعد التعامل الذكي مع وكلاء الذكاء الاصطناعي (صلاحيات الأدوات Permissions، إدارة السياق والـ Tokens).
   - مسار العمل الهندسي المعتمد من الفكرة إلى الإنتاج.

2. **الموضوع 02: استجواب الفكرة (Grill Me) وصياغة وثيقة PRD.md ومراجعتها نقدياً**
   - أسلوب المقابلة الاستجوابية المتدرجة وحسم نطاق الـ MVP.
   - الأقسام الـ 27 الكاملة لوثيقة متطلبات المنتج ومعايير القبول (Given / When / Then).
   - المراجعة النقدية للـ PRD لكشف التناقضات والفجوات المعمارية.

3. **الموضوع 03: نمذجة مسارات وتجربة المستخدم (User Flow Modeling)**
   - الفرق الهندسي بين PRD و User Flow.
   - نمذجة مسارات الاستعارة ونقاط القرار (Decision Points) ومسارات الفشل والنجاح في BorrowHub.
   - برومبتات وصيغ Mermaid flowchart TD.

4. **الموضوع 04: نمذجة الأنظمة والمخططات الهندسية المعمارية (UML Diagrams)**
   - جدول المخططات وأدوات رسمها والهدف الأساسي لكل مخطط.
   - النموذج المفاهيمي (Conceptual Domain Model).
   - مخطط حالات الاستخدام (Use Case Diagram بـ PlantUML).
   - مخطط سير العمليات (Activity Diagram مع مسارات السباحة Swimlanes).
   - مخطط تسلسل التفاعلات الزمني (Sequence Diagram مع الشروط alt/else/end).
   - مخطط دورة حياة الكيان والآلة الحالة (State Machine Diagram).
   - التصميم البنيوي للكلاسات (Design-Level Class Diagram).
   - مقارنة العدسات الهندسية المختلفة وفك الاشتباك بين المخططات.

5. **الموضوع 05: هندسة وتصميم قواعد البيانات وأداء الاستعلامات (ERD & Database Performance)**
   - تصميم الجداول الخمسة الرئيسية في BorrowHub والمفاتيح (PK / FK).
   - القيود (Constraints) والتطبيع (Normalization 3NF).
   - كود DBML ومخططات Mermaid erDiagram.
   - هندسة الأداء: حل مشكلة الاستعلامات المتكررة (N+1 Query Problem) بـ JOIN والتحميل المسبق (Eager Loading).
   - فهارس قواعد البيانات (Indexes) ومبدأ البحث الثنائي وتكلفة الكتابة.

6. **الموضوع 06: الصورة المعمارية الكبرى وتوزيع المسؤوليات (System Architecture & Backend Layers)**
   - تكامل طبقات Frontend و Nginx و Backend Layers و Database.
   - فصل المسؤوليات في الكود: Controllers / Views، Services، Selectors.
   - التخزين المؤقت وطوابير المهام غير المتزامنة: متى نستخدم Redis و Background Workers؟
   - معمارية العزل المتعدد للمستأجرين (Multi-Tenancy) وشروط تطبيقها.

7. **الموضوع 07: تنظيم ملفات المشروع وإدارة الإصدارات (Git, GitHub & Docs Structure)**
   - الهيكلية الكاملة المعتمدة لمجلد التوثيق (`BorrowHub/docs/` و `diagrams/`).
   - القواعد الست الحاسمة لضمان اتساق قواعد العمل عبر المخططات.
   - دورة العمل على الفروع (Branching)، حماية ملفات البيئة `.env`، والـ Pull Requests.

8. **الموضوع 08: تصميم الواجهات وتوليد النظم البصرية (UI/UX & Google Stitch)**
   - الانتقال من المخططات التجريدية إلى الشاشات التفاعلية.
   - التأسيس والتوجه البصري وفلسفة التصميم في Google Stitch.
   - بناء الـ Design System المتكامل (الألوان، التايبوجرافي، المسافات، الحالات التفاعلية).

9. **الموضوع 09: الربط البرمجي بين التصميم والكود (Stitch MCP & DESIGN.md)**
   - بروتوكول سياق النموذج (Model Context Protocol - MCP) والاتصال مع محررات الذكاء الاصطناعي.
   - استخراج شاشات التصميم وتشريح وثيقة `DESIGN.md` كجسر إلزامي للكود.

10. **الموضوع 10: التخطيط الهندسي وتنفيذ الفرونت إند (Frontend Implementation & Spec Kit)**
    - استراتيجية تفكيك المهام الصغيرة القابلة للتحقق (Small Verifiable Tasks).
    - دستور وقواعد المشروع البرمجي (`docs/rules/frontend.md`).
    - دورة أوامر Spec Kit الثمانية ومراجعة UI/UX Pro Max الدقيقة للجودة.

11. **الموضوع 11: مصفوفة الفحص الشامل وضمان الجودة (Comprehensive QA Matrix)**
    - مصفوفة الفحوصات الخمسة للواجهة الأمامية (التجاوب عبر 5 نقاط توقف، انعدام الطفحان الأفقي Zero Overflow، سهولة الوصول A11y، التباين، والتحقق عبر أوامر الطرفية).

12. **الموضوع 12: أسئلة التأكد من الفهم والقواعد الذهبية والقاموس التقني (FAQ, Golden Rules & Glossary)**
    - أسئلة الفهم الخمسة الأساسية وأجوبتها المعمارية.
    - الخلاصة الذهبية الشاملة.
    - جدول البرومبتات الكامل القابل للنسخ بنقرة واحدة.
    - قاموس المصطلحات البرمجية والمعمارية التفاعلي مع البحث السريع.
