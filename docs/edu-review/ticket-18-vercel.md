# مراجعة تعليمية: نشر واجهة Vercel (الموضوع 52)

**التذكرة:** مسار المشروع 18 — GitHub #22
**الموضوع:** 52 · `vercel-frontend-deployment`
**تاريخ مراجعة المحتوى والمراجع:** 2026-10-19
**المخرج المتوقع:** رابط معاينة ورابط إنتاج لواجهة Next.js المختارة، وإعدادات متغيرات عامة منفصلة عن أسرار الخادم، وسجل فحص واضح للنشر.

## دليل المراجعة التعليمية

- راجعت هدف الموضوع ومتطلباته السابقة وخطواته ومخرجاته وقائمة التحقق مقابل انتقال المسار من واجهة Next.js ومستودع Git إلى نشر الواجهة ثم استكمال Backend في الموضوع 54.
- راجعت محتوى مسار Git والمعاينات والإنتاج في [وثائق Vercel لـ Git](https://vercel.com/docs/git) و[دليل Next.js على Vercel](https://vercel.com/docs/frameworks/full-stack/nextjs).
- تحققت من أن تغييرات متغيرات البيئة تحتاج إلى نشر جديد في [إدارة متغيرات Vercel](https://vercel.com/docs/environment-variables/managing-environment-variables)، ومن أن بادئة `NEXT_PUBLIC_` مخصصة لقيم يقرؤها المتصفح في [متغيرات الأطر](https://vercel.com/docs/environment-variables/framework-environment-variables).
- راجعت خطوات النطاق وDNS وشهادة SSL في [وثائق النطاق المخصص](https://vercel.com/docs/domains/set-up-custom-domain)، ومكان فحص البناء في [وثائق سجلات النشر](https://vercel.com/docs/deployments/logs).
- لا يطلب الشرح رفع الواجهة مرتين، ويوفر رابط تجاوز إلى Netlify، ثم رابط متابعة مباشر للموضوع 54. يوضح صراحة أن نشر الواجهة لا ينشر API أو قاعدة البيانات.
