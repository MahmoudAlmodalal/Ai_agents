## 1. Summary of implementation and owner decision alignment

Per the course-owner decisions recorded on 2026-10-20 in [`docs/edu-review/owner-decision-package-70.md`](owner-decision-package-70.md) (v2, Course-owner decisions section, MahmoudAlmodalal):
- **Approved export contract and scope:** The learning export is a downloadable ZIP snapshot generated from actual local browser records in the current browser on the learner's device and the application's accessible resources. Import, restoration, and cross-device migration are explicitly out of scope and excluded from this package.
- **Concrete package format and directory organization:** The archive uses a dependency-free, traversal-safe, UTF-8 encoded ZIP format containing:
  - Root `manifest.json`: Top-level package manifest recording `packageSchemaVersion`, `generatedAt`, `scope` (`this-browser-and-device`), `recordsStatus` (`readable-from-current-browser` or `partial-or-unconfirmed`), individual `recordStorageStatus`, `fileCount`, and the complete list of included files.
  - Root `README.md`: Bilingual educational overview describing package contents, explaining that the archive is a readable snapshot only, disclaiming import/sync/migration, and disclaiming independent project grading or accreditation.
  - `learner-data/records.json`: Raw structured snapshot of browser-local records: `recentlyViewed`, `bookmarks`, `unresolvedRecentlyViewed`, `unresolvedBookmarks`, `quizAttempts` (with question versions, policy versions, attempt scores, retries, preview flags), `practicalAssessments` (with criterion versions, descriptive rating levels, scale versions, history), `checklistActivity` (with topic-specific selections, session-only flags, unresolved keys), `badgeAwardEvents`, `promptCustomizations`, and storage statuses.
  - `learner-data/activity-summary.md`: Human-readable Arabic markdown summary breaking down available local activity counts, storage status at export time, and educational interpretation rules (recent views record visit only without completion; quizzes and rubrics are self-check records without mastery claims).
  - `course/topics/[slug]/lesson.html`: Standalone offline-viewable HTML file for each of the 58 canonical Topics with scripts stripped for security.
  - `course/topics/[slug]/learning-summary.md`: Structured Arabic markdown summary for each of the 58 canonical Topics containing metadata, goal, prerequisites, implementation steps, expected outputs, learner checklist, diagram inventory and references, and versioned quiz/rubric specifications.
  - `course/topics/[slug]/diagrams/[perspective].mmd`: Mermaid source files for each exposed perspective (`architecture`, `flow`, `sequence`) across all 35 diagram-enabled Topics (105 total `.mmd` files).
  - `course/learning-content/[slug].json`: Machine-readable versioned curriculum, quiz questions, scoring policies, and practical rubric definitions for all 58 Topics.
  - `resources/reference-guides/[slug].md`: Readable field outlines for all 14 reference templates, retaining associated topic slugs, inputs, outputs, lifecycle, and field descriptions.
  - `resources/availability-manifest.json`: Full accounting of included resources and honest declarations of unavailable or non-downloadable materials: 14 template field outlines included while full downloadable template files are marked `not-available`; 190 expected learner project outputs cataloged as `not-included` with explanation; `learnerProjectFilesNotAccessible: true`; 58 external candidate videos marked `included: false` with explanation; rendered SVGs noted as not generated by the exporter; and topics without Mermaid diagrams identified.
  - `prompts/original/[slug].txt` and `prompts/original/[slug].json`: Original prompt text and structured metadata (title, category, difficulty, operation, purpose, sourceGroup, sourceLabel, topicRefs, sourceRevision) for all 41 library prompts.
  - `prompts/customized/[slug].txt`: Customized text for any saved browser customizations, plus `prompts/customizations.json` detailing revision matching and source availability.
- **Distinct activity records:** Reading visits, bookmarks, quizzes, practical rubrics, application checklists, and prompt customizations remain strictly separated. The exporter never conflates visits with completion, never converts self-assessments into mastery certifications, and never invents activity for untouched topics.
- **Honest handling of missing materials and edge cases:**
  - Empty profiles generate a valid archive with zero-activity counts, honest available status, and no fabricated entries.
  - Storage failures, corrupt storage, and blocked reads set `manifest.recordsStatus` to `partial-or-unconfirmed`, set individual storage status to `read-error`, `write-error`, or `invalid`, and update the UI message to `بدأ تنزيل الحزمة. تتضمن ملف السجلات حالة التخزين، وقد تكون بعض البيانات غير متاحة.` instead of falsely reporting a complete export.
  - Failed package generation (e.g. storage or blob failure) catches the error, sets UI state to `error`, and displays `تعذر إنشاء الحزمة أو بدء تنزيلها. لم يتم تأكيد نجاح التصدير.` without claiming success or initiating an incomplete download.
  - Files stored on the learner's local computer outside the browser sandbox are explicitly disclosed as inaccessible.
- **Accessibility and RTL support:** The export trigger button in the dashboard has accessible touch targets (>= 44px), visible keyboard focus rings (`focus-visible:ring-2`), live region announcements (`aria-live="polite"`), and full RTL Arabic layout.

## 4. Edge cases, limits, and deviations

- **No import, restore, or migration:** This package is intentionally and exclusively a read-only local snapshot. As accepted under DEC-70, no import parser or cross-device migration exists.
- **Learner Project files:** The application executes inside the browser sandbox and has no access to the learner's local file system outside the application. All 190 anticipated project outputs are honestly marked as `not-included`.
- **External video files:** Video candidates require live external connections and are never bundled into the export package.
- **Diagram representations:** Mermaid text source (`.mmd`) is included for all 35 diagram-enabled Topics across 3 perspectives. Server/client SVG rasterization is not performed inside the ZIP generator.
- **Reading completion:** No reading completion indicator or percentage is computed, aligning strictly with course-owner decision DEC-70.
