# مراجعة تعليمية شاملة: تذكرة [مسار المشروع 07]

**المسار التسلسلي:** المواضيع 18 و19 و20 ضمن مسار بناء مشروع الطالب (1–58)  
**تاريخ المراجعة:** 2026-10-18  
**المراجع:** مهندس مسار تعليمي (Educational Path Reviewer)

## 1. ملخص المراجعة ونطاق العمل

ينتقل المتدرّب في هذه التذكرة من مرحلة النمذجة المعمارية للبيانات والمسارات إلى مرحلة هندسة تجربة المستخدم وتخطيط الشاشات، وذلك عبر ثلاثة مواضيع تعليمية مستقلة تؤسس للمنتج قبل فتح أداة التصميم المرئي (Google Stitch) أو كتابة كود الواجهة (Next.js):
1. **الموضوع 18 (UI/UX - الأدوار وهيكلية التنقل):** التمييز المعماري بين UI وUX وهندسة المعلومات (IA)، توزيع صلاحيات الأدوار على الواجهة (Role-Based UI Matrix)، هندسة التنقل مع مراعاة خصوصية اللغة العربية (RTL)، وإجراء مقابلة UI/UX Grill Me التفاعلية (PROMPT 14) لإخراج `docs/UI_UX_REQUIREMENTS.md`.
2. **الموضوع 19 (UX Blueprint - الرحلات وحالات الواجهة الشاملة):** بناء خريطة الموقع (Sitemap) بصيغة كود Mermaid نصي، ورسم رحلات المستخدم المكتملة لنطاق MVP، ومواصفة السلوك الدقيق للحالات الست الإلزامية (التحميل، الفراغ، الخطأ، النجاح، التجاوب، والوصول) وتوثيقها في `docs/UX_BLUEPRINT.md` عبر PROMPT 15.
3. **الموضوع 20 (Screen Inventory - جرد الشاشات وهندسة النطاق):** حصر شاشات النسخة الأولى بدقة وربط كل شاشة بهدفها، أدوارها، مسارها، مكوناتها، بياناتها، إجراءاتها، وحالاتها الخاصة، مع إرساء القاعدة الذهبية الصارمة: **حظر اختراع أي شاشات زائدة أو استباق ميزات مستقبلية خارج MVP**، وتوثيق التغطية لقواعد العمل في `docs/SCREEN_INVENTORY.md`.

## 2. جدول المراجعة التعليمية التفصيلية لكل موضوع

### الموضوع 18: تصميم تجربة وواجهة المستخدم (UI/UX): الأدوار وهيكلية التنقل (`ui-ux-roles-navigation`)
- **الموقع في المسار (sequencePosition):** `18`
- **المعرّف الثابت (slug):** `ui-ux-roles-navigation`
- **حالة النشر:** `unified-complete`
- **المخرج المتوقع (Expected Output):**
  - ملف `docs/UI_UX_REQUIREMENTS.md` متضمناً متطلبات الواجهة المعتمدة.
  - مصفوفة صلاحيات الأدوار على الواجهة (Role-Based UI Matrix) توضح ما يراه الزائر، الطالب، ومشرف المستودع.
  - هيكلية التنقل وأنماط التصفح العربية (RTL) مع أيقونات الاتجاهات المناسبة ومخطط Mermaid لمسارات التنقل.
  - استيعاب الطالب لمنهجية المقابلة التفاعلية عبر `PROMPT 14 — UI/UX Grill Me` لطرح سؤال واحد في كل مرة دون اختراع ميزات.
- **دليل الفحص والشواهد (Inspected Evidence):**
  - تم فحص الصفحة في المسار `/learn/ui-ux-roles-navigation` والتأكد من ظهور ترويسة الموضوع والوسوم الهندسية المعيارية.
  - تم فحص اتجاه الصفحة: شروح عربية بـ `dir="rtl"`، بينما كتل الأكواد والمخططات منضبطة بـ `dir="ltr"`.
  - تم فحص جدول مصفوفة الأدوار بالكامل في سياق دراسة حالة BorrowHub: حظر الإعارة على الزائر غير المسجل، وحصر مراجعة الطلبات على المشرف.
  - تم فحص كود Mermaid flowchart TD لهيكلية التنقل وتأكيد وضوح تفرعات الأدوار.
  - تم فحص تضمين نص `PROMPT 14` المعتمد كاملاً، وزر النسخ المباشر الذي يقدم تغذية راجعة فورية `✓ تم النسخ!`.
  - تم التأكد من ربط روابط التنقل التالي للموضوع 19 (`/learn/ux-blueprint`).
- **الفجوات المرصودة (Gaps):** لا توجد فجوات.
- **النتيجة (Status):** **Passed**

### الموضوع 19: مخطط تجربة المستخدم (UX Blueprint): الرحلات وحالات الواجهة الشاملة (`ux-blueprint`)
- **الموقع في المسار (sequencePosition):** `19`
- **المعرّف الثابت (slug):** `ux-blueprint`
- **حالة النشر:** `unified-complete`
- **المخرج المتوقع (Expected Output):**
  - ملف `docs/UX_BLUEPRINT.md` لمشروع الطالب.
  - خريطة الموقع (Sitemap) ومسارات MVP بصيغة كود Mermaid flowchart TD قابل للتصيير.
  - مصفوفة تفصيلية للحالات الست الإلزامية:
    1. **التحميل (Loading):** استخدام Skeleton Screens للبطاقات بدلاً من شاشات الانتظار البيضاء لمنع Layout Shift.
    2. **الفراغ (Empty):** رسائل توجيهية إيجابية مع زر إجراء فوري (CTA) بدلاً من الشاشات الميتة.
    3. **الخطأ والتعافي (Error):** لغة إنسانية واضحة، تحديد الحقل المعطوب، وتوفير مسار تعافٍ مباشر.
    4. **النجاح (Success):** إشعارات تأكيد برقم الطلب وتحديد الخطوة التالية ومهلة الاستلام (48 ساعة).
    5. **التجاوب (Responsive):** تصميم مرن يبدأ من الجوال (390px) ومساحات لمس $\ge$ 44px.
    6. **إمكانية الوصول (Accessibility):** تباين WCAG AA بنسبة 4.5:1، حلقة التركيز للوحة المفاتيح، وخصائص ARIA.
  - تضمين `PROMPT 15 — UX Blueprint + Screen Inventory` كاملاً بنصه المعتمد.
- **دليل الفحص والشواهد (Inspected Evidence):**
  - تم استعراض وفحص صفحة `/learn/ux-blueprint`؛ التأكد من وجود الهدف وخطوات التطبيق وقائمة التحقق.
  - تم فحص خريطة مسارات BorrowHub المصاغة بـ Mermaid: تغطي المسار العام والمسارات المحمية للطالب والمشرف بدقة.
  - تم فحص الجدول الشامل للحالات الست وتطبيقاتها الميدانية الحية.
  - تم فحص نص `PROMPT 15` وزر النسخ السريع الذي يعمل بنجاح.
  - تم فحص روابط التنقل التسلسلي (السابق: موضوع 18، التالي: موضوع 20) واختبار الانتقال عبر Playwright.
- **الفجوات المرصودة (Gaps):** لا توجد فجوات.
- **النتيجة (Status):** **Passed**

### الموضوع 20: جرد الشاشات (Screen Inventory): حصر الشاشات وربط الأهداف والبيانات والحالات (`screen-inventory`)
- **الموقع في المسار (sequencePosition):** `20`
- **المعرّف الثابت (slug):** `screen-inventory`
- **حالة النشر:** `unified-complete`
- **المخرج المتوقع (Expected Output):**
  - ملف `docs/SCREEN_INVENTORY.md` المعتمد للمشروع.
  - الالتزام التام بالقاعدة الذهبية: **حظر اختراع أي شاشات زائدة عن نطاق MVP**.
  - تصنيف أولويات الشاشات (Core vs Supporting vs Future/Out of Scope).
  - جدول جرد الشاشات الكامل لمشروع BorrowHub متضمناً الشاشات الست المؤكدة:
    - `SCR-01`: الرئيسية والتعريف (`/`)
    - `SCR-02`: كتالوج المعدات والبحث (`/equipment`)
    - `SCR-03`: تفاصيل المعدة ونموذج الطلب (`/equipment/[id]`)
    - `SCR-04`: لوحة إعارات الطالب (`/dashboard/loans`)
    - `SCR-05`: لوحة مراجعة وتسليم المشرف (`/staff/requests`)
    - `SCR-06`: فحص الاسترجاع ورصد الأضرار (`/staff/inspections`)
  - مصفوفة تدقيق التغطية الهندسية (Traceability Matrix) لربط قواعد PRD (القواعد 3 و7 و8) بالشاشات.
- **دليل الفحص والشواهد (Inspected Evidence):**
  - تم فحص صفحة `/learn/screen-inventory`؛ ظهور صندوق التنبيه البارز "قاعدة المنع الصارم (No Invented Screens)" بوضوح مانع.
  - تم فحص جدول جرد الشاشات الست ومطابقة حقولها العشرة (المعرف، الاسم، المسار، الدور، الهدف، المكونات، البيانات، الإجراءات، التحقق، وتخصيص الحالات).
  - تم فحص جدول مصفوفة التتبع والتأكد من تغطية:
    - قاعدة PRD رقم 3 (جهازان كحد أقصى) على شاشة SCR-03.
    - قاعدة PRD رقم 7 (استلام العتاد خلال 48 ساعة) على شاشتي SCR-04 وSCR-05.
    - قاعدة PRD رقم 8 (توثيق الأضرار والأعطال) على شاشة SCR-06.
  - تم فحص القالب المعياري لملف `docs/SCREEN_INVENTORY.md` مع زر النسخ السريع.
  - تم التحقق من ربط زر التنقل السابق للموضوع 19 (`/learn/ux-blueprint`).
- **الفجوات المرصودة (Gaps):** لا توجد فجوات.
- **النتيجة (Status):** **Passed**
