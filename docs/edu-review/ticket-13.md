## 1. ملخص المراجعة ونطاق العمل

تغطي هذه التذكرة المحطة التأسيسية لخادم وقاعدة بيانات ومعمارية API لمشروع الطالب (Backend & Database Foundations). تأتي هذه المحطة مباشرة بعد اكتمال مرحلة تنفيذ واجهة المستخدم بنمط الفرونت إند (المواضيع 30–37)، وتمهد الطريق للمواضيع اللاحقة التي يختار فيها الطالب بديل إطار العمل (الموضوع 41: Django أو الموضوع 42: FastAPI).

تُقدم المعارف والمهارات في ثلاثة مواضيع مستقلة ومتتابعة ومترابطة عضوياً:
1. **الموضوع 38 (Python: أساسيات الخادم وتهيئة البيئة):** التركيز على المستوى اللازم للمشروع من لغة Python (الأنواع، الدوال، التعامل مع الاستثناءات) دون استطراد أكاديمي مطول، مع تهيئة البيئة الافتراضية المعزولة (`.venv` و`uv`)، وإدارة الحزم، وفصل الأسرار في `.env` وعزلها عن مستودع Git مع توثيق `.env.example`.
2. **الموضوع 39 (PostgreSQL: إعداد قاعدة البيانات والاتصال والأسرار):** تهيئة قاعدة البيانات العلائقية ومطابقتها لجداول ERD الخمسة في مشروع BorrowHub، وصياغة سلسلة الاتصال المعيارية وتأمين بيانات الاعتماد في متغيرات البيئة، وضبط تجميع الاتصالات (Connection Pooling)، مع تحقيق **الفصل الجذري الحاسم بين تخطيط قاعدة البيانات (المواضيع 14–15) وتطبيق مخططها الفعلي عبر آلية الترحيل (Migrations) في بديل الإطار الذي تختاره**.
3. **الموضوع 40 (معمارية Backend وعقود API):** ارتكاز معمارية الخادم على متطلبات PRD وجداول ERD وعقود الفرونت إند في TypeScript (الموضوع 30)، وتحديد مسارات RESTful، وتوحيد هياكل الطلبات والاستجابات الناجحة (Success Envelope) وأغلفة الأخطاء القياسية (Standardized Error Envelope)، وتوثيق مصفوفة الصلاحيات (RBAC Matrix) للأدوار الثلاثة (Student, Staff, Admin).
4. **تأكيد الحدود التعليمية الصارمة:** التزام تام بمعيار القبول: *«لا ينشئ تنفيذ هذه التذكرة Backend للموقع التعليمي نفسه»*؛ حيث تقتصر المخرجات على إرشاد وبناء مشروع الطالب مع بقاء الموقع التعليمي واجهة تفاعلية مستقلة.
