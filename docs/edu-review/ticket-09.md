## 1. ملخص المراجعة ونطاق العمل

تحقق هذه التذكرة نقلة نوعية في الترتيب البيداغوجي لمسار سلاح العصر؛ حيث تنقل أدوات التنفيذ البرمجي المتقدمة (AI Coding Agent، وGoogle AI Studio، وSkills، وMCP) من بداية المسار إلى موقعها الهندسي الصحيح: **عند الانتقال من التصميم والنموذج التفاعلي إلى تنفيذ كود الفرونت إند**.

تغطي التذكرة أربع محطات تعليمية متتابعة ومستقلة:
1. **الموضوع 24 (وكيل البرمجة بالذكاء الاصطناعي - AI Coding Agent):** تهيئة الوكيل المنفذ للمهام البرمجية، وتوضيح نموذج الصلاحيات المتدرج (قراءة، كتابة، تشغيل أوامر الطرفية مع اشتراط الموافقة البشرية للأوامر التدميرية)، وحماية الأسرار عبر `.env.local` وتأمين `.gitignore`، وإدارة نافذة السياق (Context Window) لتفادي ظاهرة التوهان في المنتصف (Lost in the Middle)، مع الالتزام الصارم بحرية اختيار الأداة (No Vendor Lock-in) وعدم افتراض أي اشتراك مدفوع أو ضمان حدود استخدام.
2. **الموضوع 25 (Google AI Studio واستكشاف النماذج):** التموضع بجانب أدوات الواجهة والتنفيذ لمنع تشتيت المراحل المبكرة من المتطلبات، واستخدام المنصة الرسمية لتجربة نماذج Gemini وضبط System Instructions ونمط الإخراج الهيكلي (Structured Outputs / JSON Mode) لتوليد بيانات تمثيلية واقعية (Mock Data) مطابقة لمخطط `docs/ERD.md`، مع عزل مفتاح API وتوضيح حدود الحصص المجانية (Rate Limits).
3. **الموضوع 26 (المهارات المخصصة - Skills):** ترسيخ القاعدة الذهبية («Agent ينفّذ، Skill يرشده، MCP يوصله بالأدوات، وPRD يحدد المطلوب»)، والتمييز الجوهري بين البرومبت اللحظي والمهارة الإجرائية الدائمة، وتوضيح أن مهارات المراحل المبكرة (مثل Grill Me) كانت أساليب حوارية استكشافية وليست متطلبات تثبيت تقنية، مع معالجة مشكلة تخمة المهارات (Skill Bloat) وبناء مهارة معايير الفرونت لمشروع الطالب (`docs/skills/frontend-standards.md`).
4. **الموضوع 27 (بروتوكول سياق النموذج - MCP):** تأسيس الفهم المعماري للبروتوكول (Host, Client, Server) وقدراته الثلاث (Tools, Resources, Prompts) وحوكمة الصلاحيات وعزل إعدادات الخوادم محلياً، كتمهيد لازم قبل ربط Stitch MCP في الموضوع 28، مع توفير المسار البديل اليدوي عند تعذر تشغيل MCP.
