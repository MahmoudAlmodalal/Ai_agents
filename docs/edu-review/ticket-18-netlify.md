# مراجعة تعليمية: نشر واجهة Netlify (الموضوع 53)

**التذكرة:** مسار المشروع 18 — GitHub #22
**الموضوع:** 53 · `netlify-frontend-deployment`
**تاريخ مراجعة المحتوى والمراجع:** 2026-10-19
**المخرج المتوقع:** رابط Deploy Preview ورابط إنتاج لواجهة واحدة على Netlify بعد مراجعة التوافق والإعدادات وHTTPS والسجلات.

## دليل المراجعة التعليمية

- راجعت أن الموضوع بديل مستقل عن Vercel، وأن الطالب يستطيع تجاوزه إذا اختار مسار Vercel، مع انتقال مباشر إلى الموضوع 54.
- راجعت دعم Next.js الحالي عبر OpenNext وحدود الميزات في [دليل Netlify لـ Next.js](https://docs.netlify.com/build/frameworks/framework-setup-guides/nextjs/overview/). يذكر الدليل أن الإعداد الحديث يختلف عن legacy runtime، لذلك لا يكرر الشرح تعليمات plugin قديمة.
- راجعت ربط مستودع Git وإعدادات البناء في [دليل النشر من مستودع](https://docs.netlify.com/start/quickstarts/deploy-from-repository/)، وسياقات المتغيرات في [وثائق متغيرات البيئة](https://docs.netlify.com/build/configure-builds/environment-variables/).
- راجعت وصف المعاينات المستقلة لـ Pull Request في [وثائق Deploy Previews](https://docs.netlify.com/deploy/deploy-types/deploy-previews/)، وإدارة HTTPS في [وثائق الشهادات](https://docs.netlify.com/manage/domains/secure-domains-with-https/https-ssl/) ومكان مراجعة البناء والوظائف في [وثائق السجلات](https://docs.netlify.com/manage/monitoring/logs/).
- يوضح الموضوع أن تغيير متغيرات الواجهة قد يعرّض القيمة للمتصفح حسب بادئة Next.js، وأن نشر واجهة فقط لا يكمل المنتج Full-Stack.
