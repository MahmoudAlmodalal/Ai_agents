## 1. ملخص المراجعة ونطاق العمل

تم في هذه التذكرة بناء **مختبر المخططات الثمانية** التفاعلي في المسار `/learn/diagram-lab` وفقاً لمواصفة مسار مشروع الطالب وكتاب محتوى سلاح العصر، لتمكين الطالب من:
1. **المقارنة المعمارية:** المقارنة بين المخططات الثمانية (User Flow, Domain Model, Use Case, Activity, Sequence, State, Class, ERD) عبر بطاقات مستقلة، وجدول مقارنة شامل (Matrix)، وأداة مقارنة ثنائية مباشرة (Side-by-Side).
2. **استيعاب الأسئلة والأغراض:** إبراز السؤال المحوري الذي يجيب عنه كل مخطط، وغرضه الهندسي، وأسئلة القرار الحاسمة لتحديد متى يختاره الطالب، مع بيان المدخلات والتبعيات.
3. **عزل حدود المحركات (Engine Boundaries):** تصيير صيغ Mermaid المدعومة محلياً داخل المتصفح (SVG)، وعرض صيغ PlantUML وDBML بمصدرهما النقي ومحررهما المعتمد دون محاولة تشغيلهما داخل Mermaid تجنباً لتعطيل العارض وتجسيداً للحالة الواقعية لأخطاء الصياغة (Grounding the engine's real error state).
4. **النسخ والتحرير:** توفير مصادر أكواد حقيقية ومقتضبة (5–15 سطراً) مستمدة من دراسة حالة BorrowHub مع نسخ بنقرة واحدة وتغذية راجعة (Toast feedback: `تم النسخ ✓`)، وروابط مباشرة للمحررات المعتمدة (Mermaid Live, PlantText, dbdiagram.io).
5. **الربط بالمسار الموحد:** ربط كل بطاقة بالموضوع المنشور المقابل في المسار التعليمي (`/learn/[slug]`) مع التحقق البرمجي الديناميكي من حالة النشر.
