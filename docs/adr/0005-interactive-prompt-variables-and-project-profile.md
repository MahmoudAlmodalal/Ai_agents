# بنية قوالب البرومبت التفاعلية وحفظ ملف تعريف المشروع محليًا

قررنا تمكين المتدرّب من تخصيص برومبتات المسار عبر نموذج متغيرات مخصص (Schema-driven Variables) مع حفظ بيانات المشروع الأساسية في «ملف تعريف المشروع» محليًا في المتصفح (`localStorage`). يتيح ذلك توليد برومبت مخصص بالكامل لمشروع الطالب تلقائيًا مع معاينة فورية وإمكانية النسخ المباشر دون الحاجة لكتابة وتكرار البيانات في كل صفحة ودون وجود خادم خلفي.

## الحالة (Status)
مقبول (Accepted)

## الخيارات التي نوقشت (Considered Options)
1. **الاستبدال النصي الديناميكي (Regex/Placeholders) في النص الخام**: رُفض لتجنب هشاشة مطابقة النصوص وللحاجة إلى أسئلة وتلميحات إرشادية دقيقة لكل متغير.
2. **استبيان متعدد الخطوات معزول (Standalone Wizard)**: رُفض لأنه يفصل الطالب عن مكتبة البرومبتات ولوحة النسخ المعتمدة ويزيد من تعقيد التنقل.
3. **تخزين مدخلات المتغيرات كملف تعريف محلي مشترك مع نموذج مدخلات مخصص لكل برومبت**: تم اعتماده لتقديم تجربة تعلّم سلسة تحفظ وقت الطالب وتمنع تكرار إدخال اسم المشروع وفكرته ونطاقه في كل برومبت.

## النتائج والآثار (Consequences)
- إثراء بيانات البرومبتات في `promptLibrary.ts` بهيكل `variables` يحتوي (المفتاح، التسمية، السؤال، والقيمة الافتراضية).
- تحديث `PromptCopyPanel` لدعم التعبئة التفاعلية والمعاينة المباشرة للنص قبل النسخ عبر تبويب «تخصيص بالمتغيرات».
- مزامنة المتغيرات المشتركة مع «ملف تعريف مشروع المتدرّب» تلقائيًا مع تمييزها بصريًا عن المتغيرات الخاصة بالبرومبت.
- اعتماد حزمة المسار المحورية كنموذج تجريبي أولي (Pilot): `Prompt 01` (استكشاف المنتج)، `Prompt 16` (Stitch Master Prompt)، و `Prompt 31` (خطة Next.js).
- الحفاظ التام على أصل البرومبت المعتمد ومطابقة نصوص الكورس الثابتة دون تغيير في رخص التوثيق.
