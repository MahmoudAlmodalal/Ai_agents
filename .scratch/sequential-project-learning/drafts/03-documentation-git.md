# 03: حفظ وثائق المشروع باستخدام Git وGitHub

**What to build:** يتعلم الطالب Git وGitHub في موضوعين مستقلين مبكرًا لحفظ وثائقه ومراجعتها، دون تقديم إعداد أدوات تنفيذ الفرونت.

**Blocked by:** 01: موضوع واحد موحّد من الفهرس إلى القراءة.

**Status:** draft-awaiting-review

- [ ] يعرض كل موضوع خطوات عملية وأمثلة مرتبطة بحفظ وثائق مشروع الطالب.
- [ ] توضح حماية الأسرار والحفظ والفروع والمراجعة دون طلب نشر غير مصرح أو روابط تنزيل غير متاحة.
- [ ] تعكس بيانات البطاقات والقارئين محتوى Git الحقيقي بدل موضوعات UML أو انتظار محاضرة.
- [ ] تُراجع أوامر الأدوات مقابل مراجعها الرسمية قبل وسمها بأنها محققة.
- [ ] يختبر التنقل والنسخ، وتسجّل مراجعة تعليمية لمخرجات الموضوعين.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
