# 24: القاموس والأسئلة الشائعة أثناء التعلم

**What to build:** يبحث الطالب في المصطلحات ويجد إجابات الأسئلة العملية والمعمارية المرتبطة بموضوعه دون انتظار نهاية المسار.

**Blocked by:** 01: موضوع واحد موحّد من الفهرس إلى القراءة.

**Status:** draft-awaiting-review

- [ ] يُعرض القاموس التقني بمصطلحات المصدر بما يشمل 35 مصطلحًا أو أكثر، ويعمل البحث العربي فيه.
- [ ] توضح الأسئلة الفروق بين الوثائق والمخططات والأدوات ومراحل Frontend وBackend دون تعارض مع قرارات الترتيب.
- [ ] تُستخدم مصطلحات المشروع المتفق عليها وتعمل الروابط إلى المواضيع المنشورة أو تظهر حالة عدم توفر واضحة.
- [ ] يفحص المتصفح البحث والقراءة والوصول، وتُراجع التعريفات والإجابات تعليميًا ودقتها.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
