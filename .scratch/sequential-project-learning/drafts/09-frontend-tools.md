# 09: أدوات التنفيذ عند بدء كود الفرونت

**What to build:** يجد الطالب مواضيع Coding Agent وGoogle AI Studio وSkills وMCP عند الانتقال من التصميم إلى تنفيذ الفرونت، بدل تحميل بداية المسار بها.

**Blocked by:** 01: موضوع واحد موحّد من الفهرس إلى القراءة.

**Status:** draft-awaiting-review

- [ ] يظهر كل موضوع مستقلًا بعد التصميم والنموذج التفاعلي في ترتيب التعلم.
- [ ] توضح الأدوات في سياق مشروع الطالب وصلاحياتها وأسرارها وإدارة السياق دون افتراض اشتراك أو ضمان حدود استخدام.
- [ ] لا تعيد المواضيع السابقة اشتراط إعداد وكيل أو Skill أو MCP قبل اكتشاف المتطلبات.
- [ ] لا يُفرض تبديل وكيل البرمجة أو شراء خدمة لتنفيذ المسار.
- [ ] يفحص المتصفح موضع المواضيع وقراءتها، وتسجّل مراجعة تعليمية لتجهيزاتها المطلوبة ومخرجاتها.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
