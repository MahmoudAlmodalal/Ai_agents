# 02: اكتشاف المشروع وكتابة PRD وSRS

**What to build:** يطبّق الطالب موضوعات Grill Me وPRD وSRS على مشروعه، ويصل لكل موضوع من الفهرس والقراء بترتيب متسق.

**Blocked by:** 01: موضوع واحد موحّد من الفهرس إلى القراءة.

**Status:** draft-awaiting-review

- [ ] لكل موضوع مستقل شرح وخطوات ومدخلات ومخرجات وقائمة تحقق، وتسبق القرارات المعتمدة الوثائق المولدة.
- [ ] تشمل PRD بنيتها المرجعية ومراجعتها، وتوضح SRS السلوك والأخطاء ومعايير القبول دون اختراع قرارات.
- [ ] يمكن إنجاز التحليل دون تثبيت أدوات كود الفرونت أو Skills أو MCP.
- [ ] تعمل البرومبتات المتاحة في هذه المواضيع ونسخها، مع تمييز الافتراضات والأسئلة المفتوحة.
- [ ] يفحص المتصفح القراءة والتنقل، وتسجّل مراجعة تعليمية لكل مخرج موضوع.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
