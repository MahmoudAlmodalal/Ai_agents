# 07: UI/UX وUX Blueprint وجرد الشاشات

**What to build:** يحوّل الطالب متطلبات مشروعه إلى احتياجات تجربة وخريطة رحلات وجرد شاشات في ثلاثة مواضيع مستقلة تسبق التصميم المرئي.

**Blocked by:** [#5](https://github.com/MahmoudAlmodalal/Ai_agents/issues/5).

**Status:** ready-for-agent

**GitHub Issue:** [#11](https://github.com/MahmoudAlmodalal/Ai_agents/issues/11)

- [ ] تعرض المواضيع الأدوار والتنقل وحالات التحميل والفراغ والخطأ والنجاح والتجاوب والوصول.
- [ ] يربط جرد الشاشات كل شاشة بهدفها وإجراءاتها وبياناتها وحالاتها، دون اختراع شاشات غير مطلوبة.
- [ ] توضح المدخلات والمخرجات والبرومبتات الخاصة بكل موضوع.
- [ ] يفحص المتصفح القراءة والتنقل والنسخ.
- [ ] تسجّل مراجعة تعليمية للتغطية بين المتطلبات والرحلات والشاشات.

نسخة مرجعية للتذكرة المعتمدة والمنشورة على GitHub. اعتمادياتها مسجلة أيضًا بعلاقات حجب فعلية؛ يبدأ التنفيذ عندما تكتمل التذاكر التي تحجبها.
