# 27: التحقق من رحلة الموقع واكتمال المراجعة التعليمية

**What to build:** يتبع المراجع مسار الطالب عبر الموقع كاملًا ويملك تقريرًا يثبت سلامة التنقل والمحتوى ومخرجات كل موضوع دون ادعاء فحوص غير منفذة.

**Blocked by:** 26: نقل المحفوظات والروابط وإنهاء الفهارس المتضاربة.

**Status:** draft-awaiting-review

- [ ] ينجح سيناريو رحلة المتصفح المعتمد من الفهرس إلى القراءة والتنقل والنسخ والمفضلة القديمة، مع وضوح حدود البداية والنهاية والبدائل.
- [ ] تتطابق الاعتماديات التعليمية بين المواضيع، وتظهر أدوات التنفيذ عند بدء الفرونت ويُتاح كل مخرج قبل استعماله.
- [ ] يحتوي التقرير مراجعة تعليمية يدوية لكل موضوع منشور: المدخلات والخطوات والبرومبت والمخرج ودليل الفحص والفجوات ومعالجتها.
- [ ] تُجمع أدلة المراجعات المنفذة في التذاكر السابقة ويُفحص اتساق المسار كاملًا؛ لا تعاد الفحوص الناجحة دون مبرر.
- [ ] تُحدّث توقعات التحقق القديمة المتعارضة مع تنظيم المواضيع، ويُفصل الفحص السلوكي عن مجرد البحث عن نص في مصدر.
- [ ] تُشغّل فحوص TypeScript والبناء الملائمة والفحص المتجاوب على العروض المرجعية، وتُسجّل Passed وFailed وNot Run بدقة.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
