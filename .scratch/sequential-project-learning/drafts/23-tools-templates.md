# 23: دليل الأدوات والقوالب المتاحة

**What to build:** يجد الطالب وظيفة الأداة ووقت استخدامها والقوالب المناسبة لمخرج خطوته، ويفتح أو ينزّل المتاح فعلًا.

**Blocked by:** 01: موضوع واحد موحّد من الفهرس إلى القراءة.

**Status:** draft-awaiting-review

- [ ] توضح صفحات الأدوات والقوالب موضوع الاستخدام ومدخلات الملفات ومخرجاتها ودورة حياتها.
- [ ] تُراجع الأوامر والروابط الحساسة للإصدار من المصادر الرسمية قبل وصفها بأنها محققة.
- [ ] تُعرض القوالب المرجعية الأربعة عشر بحالة توفر دقيقة وروابط تعمل للملفات الموجودة فقط.
- [ ] تظل أدوات التنفيذ مرتبطة بوقت الفرونت ولا تعيد الصفحة فرض تجهيزها في بداية التحليل.
- [ ] يفحص المتصفح البحث أو التنقل والنسخ والتنزيل الحقيقي؛ تُراجع القوالب تعليميًا مقابل مخرجات المسار.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
