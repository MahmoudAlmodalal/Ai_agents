# 01: موضوع واحد موحّد من الفهرس إلى القراءة

**What to build:** يقرأ الطالب موضوع اختيار فكرة المشروع بالعنوان والخطوات والمخرجات نفسها من بطاقة الرئيسية ومن صفحة الموضوع ومن القارئ التفصيلي، مع هوية ثابتة مستقلة عن رقم الترتيب.

**Blocked by:** None (can start immediately).

**Status:** draft-awaiting-review

- [ ] تتوفر قراءة متسقة للموضوع عبر الواجهات الحالية وروابط صالحة وحدود تنقل واضحة.
- [ ] يتوسع نموذج الموضوع الحالي تدريجيًا دون حذف المحتوى أو تعطيل بقية القراء قبل ترحيلهم.
- [ ] يتضمن الموضوع هدفًا ومدخلات وخطوات وبرومبتًا عند الحاجة ومخرجًا وقائمة تحقق وحالة نشر صادقة.
- [ ] لا تعاد نسبة المفضلة أو المشاهدات القديمة لموضوع مختلف بسبب رقم الترتيب.
- [ ] يوجد فحص متصفح للرحلة الأولى وتسجيل مراجعة تعليمية لمخرج تحديد المشروع.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
