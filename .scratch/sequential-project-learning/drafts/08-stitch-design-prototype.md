# 08: Stitch ونظام التصميم وPrototype

**What to build:** يصمم الطالب شاشة مرجعية ثم نظامًا بصريًا وبقية الشاشات ونموذجًا تفاعليًا في مواضيع مستقلة، قبل إعداد أدوات الكود.

**Blocked by:** 01: موضوع واحد موحّد من الفهرس إلى القراءة.

**Status:** draft-awaiting-review

- [ ] تبدأ خطوات Stitch بشاشة مرجعية واحدة قبل توليد بقية الشاشات.
- [ ] تُشرح قواعد نظام التصميم وتطبيقها على برومبتات شاشات منفصلة.
- [ ] يتحقق Prototype من الرحلات والحالات بدل عرض زر تجربة وهمي.
- [ ] تُعرض المراجع والملفات حسب توفرها الفعلي، ولا تُخترع روابط أو قيم بصرية معتمدة.
- [ ] يفحص المتصفح المحتوى والنسخ والروابط، وتسجّل مراجعة تعليمية لمخرجات المواضيع الثلاثة.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
