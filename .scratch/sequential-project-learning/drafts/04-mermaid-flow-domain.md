# 04: Mermaid وUser Flow وDomain Model

**What to build:** ينتقل الطالب من تعلّم صيغة Mermaid إلى رسم رحلة مشروعه ونموذجه المفاهيمي في ثلاثة مواضيع مستقلة.

**Blocked by:** 01: موضوع واحد موحّد من الفهرس إلى القراءة.

**Status:** draft-awaiting-review

- [ ] تُعرض أمثلة Mermaid ومصادرها القابلة للنسخ والشرح بالعربية باتجاهات صحيحة.
- [ ] تظهر مسارات النجاح والفشل والقرارات مرتبطة بمتطلبات موثقة.
- [ ] يبقى Domain Model مفاهيميًا دون مفاتيح قاعدة بيانات أو أنواع SQL أو دوال.
- [ ] تعمل الأمثلة في العارض الموجود، وتُظهر الأخطاء بوضوح إن فشل رسم دون تعطيل القراءة.
- [ ] تُفحص الواجهة وتسجّل مراجعة تعليمية لكل موضوع ولمطابقة الرسوم للمتطلبات.

هذه مسودة مراجعة، وليست تذكرة منشورة أو جاهزة للسحب قبل اعتماد التقسيم وتهيئة المتعقّب.
