# 03: قائمة تحقق تطبيق محفوظة ومتسقة بين القارئين

**GitHub Issue:** [#36](https://github.com/MahmoudAlmodalal/Ai_agents/issues/36) — منشورة ومعتمدة؛ الموجة الأولى C.

## Parent

[مواصفة نموذج تحسين تجربة التعلّم #33](https://github.com/MahmoudAlmodalal/Ai_agents/issues/33)

## What to build

يؤشر المتعلّم معايير التطبيق بنفسه، ويجد اختياراته عند العودة أو تحديث الصفحة وعلى القارئين في نفس المتصفح والجهاز، دون خلط ذلك بتقدم القراءة.

## Acceptance criteria

- [ ] يمكن اختيار بنود قائمة تحقق التطبيق وإلغاء اختيارها في المعاينة والقراءة الكاملة، وتظهر الاختيارات نفسها عند التنقل بين القارئين.
- [ ] تُستعاد الاختيارات بعد تحديث الصفحة والخروج من الموضوع والعودة إليه في نفس المتصفح والجهاز، دون حساب أو خادم أو مزامنة أجهزة.
- [ ] ترتبط العلامات بهوية الموضوع ومعنى بند التحقق، ولا تنتقل لموضوع آخر أو لبند مختلف بسبب إعادة الترتيب أو تبدل النص.
- [ ] تُحافظ على بيانات الحفظ السابقة عند وجود تطابق موثوق، دون اختلاق تطابق أو تغيير معنى العناصر المحفوظة القديمة.
- [ ] يبقى المحتوى والتفاعل بالقائمة عاملين عند تعذر التخزين أو تلف بياناته، دون انهيار أو تأكيد حفظ مضلل.
- [ ] تُقدم القائمة كتقييم ذاتي منفصل عن تقدم القراءة؛ لا يؤدي تمرير النص أو فتح الموضوع إلى اختيار البنود أو تقييم صحة العمل أو قفل الموضوع التالي.
- [ ] يمكن البدء بالقائمة الحالية؛ يتعامل السلوك مع تغيّر معايير الموضوع بأمان، فلا يتطلب انتظار إعادة كتابة المحتوى أو تغيير إجراء الدخول.
- [ ] يغطي تحقق سلوكي عبر المتصفح الاختيار والإلغاء والتحديث والعودة والتبديل بين القارئين وعزل المواضيع وإعادة الترتيب، مع تغطية فشل التخزين عند حد قراءته وكتابته. تُراجع قابلية استخدام القائمة بلوحة المفاتيح وعلى الهاتف.

## Blocked by

None (can start immediately).
