## What to build

يتبع المراجع رحلة المتعلّم من البداية حتى مخرج مشروعه واستعادة قائمة التحقق، ويستلم نموذجًا متسقًا وأدلة واضحة لمراجعته قبل تعميم نمطه.

## Acceptance criteria

- [ ] تُجرب رحلة واحدة متكاملة من الرئيسية إلى القراءة المباشرة والمعاينة والمثال والتمرين وقائمة التحقق والتحديث والعودة، مع تطابق هوية الموضوع والمادة والحالة بين القارئين.
- [ ] تُعالج عوائق التكامل المرصودة في التنقل أو عرض المادة أو حفظ الاختيارات، ثم تُعاد الفحوص المتأثرة؛ لا تعوض هذه المهمة غياب اختبارات السلوك المطلوبة في المهام السابقة.
- [ ] تُثبت مراجعة تعليمية فعلية إمكانية إنتاج سياق المشروع ونطاق MVP من الشرح والتمرين وكفاية المخرج للخطوة التالية، مع بقاء BorrowHub مثالًا اختياريًا.
- [ ] تُفحص القراءة والتنقل والتركيز ولوحة المفاتيح واتجاه النص والكود وعدم التدفق الأفقي عند عروض 390 و768 و1024 و1366 و1440 بكسل.
- [ ] تُراجع الوظائف الحالية المتأثرة: البحث والتصفية والمفضلة وسجل المشاهدة والنسخ والثيم والصوت والطباعة؛ يُسجل دعم الصوت وما جُرب فعليًا دون ادعاء تشغيل لم يُفحص.
- [ ] تُراجع حالة المحتوى التالي غير المستكمل وحرية الانتقال، ولا يضاف مؤشر إتقان أو قفل تقدم أو ادعاء اكتمال بقية المواضيع.
- [ ] تُجرى فحوص الأنواع وبناء الإنتاج وفحوص الرحلة المناسبة، ويسجل التقرير الدليل والنتائج Passed أو Failed أو Not Run والقيود والمخاطر المتبقية.
- [ ] يُسلّم نموذج الرئيسية والموضوع الأول ونتائج تحققه لمالك المحتوى للمراجعة قبل التعميم. لا تشمل المهمة تعميم النمط أو تنفيذ بقية المواضيع أو إغلاق المواصفة الأم تلقائيًا.
